# Acknowledgements

This project learns from existing open-source work. These are design references, not claims that their implementations were copied.

- [Delegate Agent](https://github.com/treygoff24/delegate-agent): explicit run ownership, scratch lifecycle, process supervision and recovery after real storage incidents.
- [Disk Steward](https://github.com/KMerdan/disk_steward): local agent evidence, allocated-space measurement, bounded stores and honest partial/unknown states.
- [Worktrunk](https://github.com/max-sixty/worktrunk): worktree hooks and independent copy-on-write cache reuse.
- [TreeMap](https://github.com/Prithvi-Web/TreeMap-Disk-Visualizer): useful folder history, comparisons and policies for automated operations.
- [gdu](https://github.com/dundee/gdu): existing scanning capabilities and filesystem-accounting lessons.
- [VS Code](https://github.com/microsoft/vscode): session-aware worktree lifecycle and protection of active work.

Copied or distributed components belong in a separate third-party notice record with exact revisions, files, original license/copyright notices and local modifications. Thanking a project does not replace its license requirements.
